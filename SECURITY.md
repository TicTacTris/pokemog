# Security Policy

## Private Reporting

Use [GitHub private vulnerability reporting](https://github.com/TicTacTris/pokemog/security/advisories/new). Do not post secrets, tokens, signing material, private screenshots or diagnostic exports in public issues. If private reporting is unavailable, request a private contact using only a non-sensitive description; wait for a private channel before sending details.

Include the affected version/platform, expected and observed behavior, impact and a minimal sanitized description. Prefer synthetic data. Do not test against other users or third-party services. Revoke exposed credentials independently of the report.

## Support And Scope

This is a volunteer-maintained beta. Review focuses on the current release and development branch; no response deadline, security warranty or paid support is promised. Tips do not purchase support. The original code's MIT license does not supersede third-party SDK terms.

The [security review](docs/SECURITY_REVIEW.md) records scoped defensive findings and pending release verification. It is not an independent audit or proof that the software is vulnerability-free. Use official release assets, verify checksums and signing identity, and read the [privacy notice](public/privacy/index.html) before screen capture or diagnostic sharing.
