Install and scan

  1. Read the release notes and verify the published checksum before installing. Trust the source, not just a matching hash. Allow your browser or file manager to install the APK only if you trust it; revoke that permission afterward.
  2. Stop capture before updating. This release uses a dedicated release signing key. Older debug-signed installations of dev.pokemog.android must be uninstalled first, losing local settings and data. Check the release notes before installing.
  3. Grant appear-on-top permission and fresh Android screen-capture consent. Prefer sharing only Pokemon GO where available. Allow notifications for Stop access. Stop full-screen capture before opening unrelated apps.
  4. Open Appraise and scan. Auto-scan is optional and off by default. Inspect results; form identity and Shadow availability may remain unresolved. Only share diagnostic captures deliberately, after checking for private information.

Android recognizes text on-device using Google ML Kit and checks GitHub for public data updates. SDK operational metrics are separate from OCR input/output. Read the privacy notice for SDK, connection metadata and diagnostic retention details. Physical-device verification remains outstanding for this beta; browser tests do not establish Android device behavior.
